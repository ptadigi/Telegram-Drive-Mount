# Ảnh chụp giao diện (Screenshots)

Thư mục này chứa ảnh dùng cho README và tài liệu. Để README trông chuyên nghiệp,
hãy bổ sung các ảnh sau (kéo–thả vào đây với đúng tên file).

## Danh sách ảnh cần chụp

| Tên file | Nội dung | Gợi ý |
|----------|----------|-------|
| `dashboard.png` | Trang chủ / dashboard (đã đăng nhập, có số liệu Tệp/Thư mục/Dung lượng) | Desktop, có vài file thật |
| `drive.png` | Màn hình Drive: lưới file/thư mục, icon màu theo định dạng | Desktop |
| `viewer.png` | Xem file trong app (ảnh zoom, hoặc video, hoặc docx) | Desktop |
| `share.png` | Hộp thoại tạo link chia sẻ + trang share công khai | Desktop |
| `mobile.png` | Giao diện trên điện thoại (bottom nav) | Khổ dọc ~390px |
| `desktop-tray.png` | App desktop ở khay hệ thống + ổ T: trong Explorer | Windows |

## Quy cách
- Định dạng **PNG**, nền sạch, không lộ thông tin nhạy cảm (email, token, file riêng tư).
- Bề ngang ~1280–1600px cho ảnh desktop; ~390–430px cho ảnh mobile.
- Đặt đúng tên ở bảng trên để README tự hiển thị (đã chèn sẵn link ảnh trong README).

## Cách chụp nhanh
- **Windows:** `Win + Shift + S` (Snipping Tool) hoặc `Win + PrtSc`.
- **Chrome (full-page/đẹp):** F12 → Ctrl+Shift+P → gõ "screenshot" → *Capture full size / area screenshot*.
- **Mobile:** chụp màn hình điện thoại khi mở PWA, hoặc dùng Chrome DevTools chế độ device.

> `og-image.png` (ở `web-pwa/public/`) là ảnh social 1200×630 dùng cho preview khi share link — không cần thay, đã tạo sẵn.
