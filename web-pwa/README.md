# PWA Ổ Đĩa Cloud Ảo

PWA mới, không phụ thuộc Tauri.

## Mục tiêu

- Giao diện tiếng Việt có dấu mặc định.
- Upload file từ điện thoại/browser.
- Quản lý file/folder.
- Stream media.
- Tạo link chia sẻ.
- Kết nối Go Agent local để xem trạng thái sync và ổ đĩa ảo.

## Chạy dev

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```
